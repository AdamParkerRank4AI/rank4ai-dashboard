Run an AI Visibility Audit

Kicks off a fresh audit on the Mac-hosted pipeline. The PDF is emailed when it finishes (typically 3 to 10 minutes depending on the version).

Include https:// or http://

Audit version

How it works

  1. Form sends the URL to a Cloudflare Pages Function.
  2. Function forwards it through the rank4ai-audit Cloudflare Tunnel to the Mac.
  3. Mac runs auditcheck.py (v1) or auditcheck_v2.py (v2).
  4. When the audit completes, the branded PDF is emailed to the team.
